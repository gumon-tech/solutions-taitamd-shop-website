# ไฟล์ใน `public/` ที่ไม่มีหน้าไหนอ้างถึง — แต่เข้าถึงได้สาธารณะ

> สำรวจ **2026-08-10** ตามคำขอของห้อง `WS` (สืบเนื่องจาก `Q-SHOP-003` เรื่องรูปครูนก)
> 🔴 **เอกสารนี้เป็นบันทึก ไม่ใช่คำสั่งให้ลบ** — `WS` สั่งชัดว่า **ยังไม่ต้องลบ**
> *"ของหายโดยไม่มีคนสั่ง แย่กว่าของค้าง"* ⇒ ให้จดไว้แล้วเสนอเจ้าของ

## ทำไมเรื่องนี้ถึงสำคัญกว่าที่ชื่อหัวข้อทำให้รู้สึก

`WS` สรุปกลไกไว้คมมากตอนสั่งงาน และมันตรงกับสิ่งที่พบ:

> 🔑 **"ไฟล์ที่ไม่มีหน้าอ้างถึง จะไม่มีใครนึกถึงตอนตัดสินใจ — มันจะรอดทุกการทบทวน เพราะไม่มีใครเห็นมัน"**

`next.config.mjs` ตั้ง `output: "export"` ⇒ **ทุกไฟล์ใน `public/` ถูก deploy ขึ้น GitHub Pages เสมอ
ไม่ว่าจะมีหน้าไหนอ้างถึงหรือไม่** · การไม่มีลิงก์ **ไม่ได้แปลว่าเข้าไม่ถึง** แปลว่า **ไม่มีใครเห็นตอนตรวจ**
