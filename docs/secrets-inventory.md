# รายการความลับของรีโปนี้ — **"ที่มา" ไม่ใช่ "ค่า"**

> เขียน **2026-08-11** ตาม [`machine-handover.md`](../../gumon-workspace/docs/machine-handover.md) ถัง C
> ⛔ **ห้ามใส่ค่าจริงลงไฟล์นี้เด็ดขาด** — ไฟล์นี้อยู่ใน git สาธารณะของทีม
> 🔑 *เครื่องใหม่ไม่ต้องการค่าเดิม มันต้องการรู้ว่าจะไปเอาค่ามาจากไหน*

## ✅ ข่าวดี: **การ deploy ไม่ต้องใช้ความลับใด ๆ เลย**

`.github/workflows/nextjs.yml` ใช้ **OIDC ของ GitHub Pages ที่ผูกกับตัวรีโปเอง** — ไม่มี `secrets.*` ในไฟล์ workflow
⇒ **clone แล้ว push ได้เลย เว็บขึ้นเอง** · ไม่ต้องขอ token จากใคร ไม่ต้องตั้งค่าอะไรก่อน
⇒ **ไม่มีความลับตัวไหนใน `.env` ที่จำเป็นต่อการ build หรือ deploy เว็บ**

## 📋 ไฟล์ `.env` ในเครื่องเก่า — 3 ตัวแปร

| ตัวแปร | เป็นความลับไหม | ใช้ที่ไหน | ขอใหม่ได้จากไหน | หมุนใหม่ได้ไหม |
|---|---|---|---|---|
| `GEMINI_API_KEY` | 🔴 **ใช่** | ⚠️ **ไม่มีโค้ดในรีโปนี้อ่านมันเลย** (ดูหมายเหตุล่าง) | Google AI Studio ด้วยบัญชี **`thanyarat.po@taitam-d.com`** (บัญชีที่ล็อกอินได้ · `info@` เป็นกลุ่ม ล็อกอินไม่ได้) | ✅ ได้ — สร้างคีย์ใหม่แล้วเพิกถอนของเก่า |
| `GEMINI_TEXT_MODEL` | ⚪ ไม่ (เป็นชื่อรุ่น ไม่ใช่ความลับ) | เหมือนกัน | เลือกรุ่นปัจจุบันจากเอกสาร Gemini ได้เลย **ไม่ต้องกู้ค่าเดิม** | — |
| `GEMINI_IMAGE_MODEL` | ⚪ ไม่ | เหมือนกัน | เหมือนกัน | — |

### ⚠️ หมายเหตุที่เครื่องใหม่ต้องรู้ — **คีย์นี้ไม่ได้ผูกกับเว็บ**

`grep -rn "GEMINI" app components lib scripts .github package.json next.config.mjs` → **0 จุด**
⇒ **ไม่มีอะไรในรีโปนี้อ่านตัวแปรสามตัวนี้** · ของที่มันเคยถูกใช้สร้างน่าจะเป็นภาพแคมเปญที่ตั้งชื่อว่า `*-gemini*.jpg`
ซึ่ง **ถูกสร้างนอกรีโปแล้วเอาไฟล์มาวางใน `public/`**

⇒ **สรุปสำหรับเครื่องใหม่: ไม่ต้องรีบขอคีย์นี้** — เว็บทำงานครบโดยไม่มีมัน
ขอเมื่อจะสร้างภาพใหม่จริง ๆ เท่านั้น (เช่นงาน [`ORPHANED-ASSETS.md`](plans/ORPHANED-ASSETS.md) ที่ต้องทำโปสเตอร์ใบใหม่)

## ✅ ตรวจแล้วว่า **ไม่มี** ความลับชนิดอื่นในเขตนี้

`kubeconfig` · token ของ registry · รหัสฐานข้อมูล · `~/.docker/config.json` — **ไม่มีเลย**
เว็บนี้เป็น **static export บน GitHub Pages** ⇒ ไม่มี server · ไม่มีฐานข้อมูล · ไม่มี container

## 🔴 บัญชีภายนอกที่ *ผูกกับเว็บนี้* แต่ห้องนี้ไม่ได้ถือ credential

**ไม่มี credential ของบริการเหล่านี้อยู่ในเครื่องหรือในรีโปเลย** — จดไว้เพื่อให้รู้ว่า *ของอยู่ที่ใคร* เวลาต้องใช้:

| บริการ | ใครถือ | หมายเหตุ |
|---|---|---|
| Google Ads (PMax ชี้ apex) · GA4 | **ห้อง Marketing Lead** + เจ้าของ | ห้องนี้ไม่เคยเข้าคอนโซล — เห็นผลผ่านรายงานของ Marketing เท่านั้น |
| GitHub (รีโป + Pages) | บัญชี GitHub ของ komphet | deploy ใช้ OIDC ไม่ใช้ token |
| โดเมน `taitam-d.com` | เจ้าของ (ผู้ให้บริการโดเมน) | โดเมนเก่า `taitamd-beautyacademy.com` อยู่บน Hostinger และกำลังถูกยกเลิก |
| Google Search Console | ⚠️ **ยังไม่มีใครตั้ง** เท่าที่ห้องนี้รู้ | ถ้าจะตั้ง **ต้องใช้ `thanyarat.po@taitam-d.com`** — `info@` เป็นกลุ่ม ล็อกอินไม่ได้ |

## Verify

```bash
grep -rn "secrets\." .github/workflows/          # คาดหวัง: ว่าง = deploy ไม่ใช้ความลับ
grep -rn "GEMINI" app components lib .github     # คาดหวัง: ว่าง = ไม่มีโค้ดอ่านคีย์
git check-ignore -v .env                         # คาดหวัง: ตรงกับกฎใน .gitignore = ไม่หลุดขึ้น git
```
