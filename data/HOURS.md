# เวลาเปิดร้าน — `data/hours.json`

แก้เวลาเปิดปิดร้านที่ไฟล์นี้ไฟล์เดียว ไม่ต้องแตะโค้ด · ทุกที่บนเว็บที่บอกเวลา (hero · footer · ตำแหน่งร้าน · FAQ · หน้า landing ·
หน้า tour · หน้า book · structured data) คำนวณจากไฟล์นี้ (`lib/hours.ts`)
ไฟล์ผิดรูป ⇒ `next build` ล้ม ⇒ deploy ไม่เกิด หน้าเว็บเดิมอยู่ต่อ

## รูปแบบ

```json
{ "days": [ { "day": "Monday", "opens": "10:30", "closes": "21:00" }, ... ] }
```

| ช่อง | ความหมาย |
|---|---|
| `days` | ครบ 7 รายการ เรียง Monday → Sunday ตามนี้เท่านั้น |
| `day` | ชื่อวันภาษาอังกฤษเต็ม (`Monday` … `Sunday`) |
| `opens` `closes` | เวลา 24 ชั่วโมง `HH:MM` · `closes` ต้องหลัง `opens` ในวันเดียวกัน (ไม่รองรับเปิดข้ามเที่ยงคืน) |
| `closed` | วันหยุดประจำสัปดาห์: `{ "day": "Sunday", "closed": true }` แทน `opens`/`closes` · ต้องเปิดอย่างน้อยหนึ่งวัน |

## ผลที่ได้

ทุกวันเหมือนกัน (ตอนนี้) ⇒ `Mon – Sun 10:30 AM – 9:00 PM` · วันไม่เหมือนกัน ⇒ ระบบรวมวันที่ติดกันและเวลาเดียวกัน เช่น
`Mon – Fri 10:30 AM – 9:00 PM, Sat – Sun 11:00 AM – 6:00 PM` · structured data (`openingHoursSpecification`) แตกเป็นกลุ่มเดียวกัน

ข้อควรระวัง: ประโยคที่เขียนว่า "open every day" หรือ "Daily" อยู่ในโค้ด/FAQ ถ้าร้านหยุดบางวัน ต้องแก้ถ้อยคำนั้นด้วย
(`HOURS.uniform` บอกว่าทุกวันเหมือนกันหรือไม่ · ป้าย "Daily" บนการ์ด hero เปลี่ยนเป็น "Hours" เอง)

## ที่ยังไม่ได้ผูก

`public/llms.txt` (บรรทัด `Opening hours`) เป็นไฟล์สถิตที่ build ไม่ได้สร้าง ⇒ แก้ด้วยมือพร้อมไฟล์นี้

## การเปลี่ยนจากระบบร้าน (shop system)

สาขา `shop-agent/hours-<id>` · ไฟล์ `data/hours.json` · workflow `.github/workflows/auto-merge-shop-agent.yml` merge เองเมื่อด่านผ่าน แล้วสั่ง deploy

ระบบทำได้ / ห้าม
- **แทนทั้งไฟล์ได้** (เวลาเปิดปิดทุกวัน · วันหยุดประจำสัปดาห์) · กติกาทั้งหมดอยู่ที่ตัวตรวจ `lib/hours.ts` ไฟล์นี้ไม่มีข้อความอิสระ
- ห้ามเพิ่มช่องระดับไฟล์นอกจาก `days`

ด่านทั้งหมดเหมือนโปรโมชัน (ดู `data/PROMOTIONS.md` หัวข้อ "การเปลี่ยนจากระบบร้าน"): PR แก้ไฟล์นี้ไฟล์เดียว ·
`npm run test:shop-agent` · `check-orphan-assets` · `next build` (ตัวตรวจของไฟล์นี้ใน `lib/`) · lint · `check:css` ·
`scripts/check-shop-agent-diff.mjs hours` · และ `main` ต้องยังไม่ขยับตอน merge · ไม่ผ่านข้อใด PR ค้างไว้ให้คน พร้อมคอมเมนต์ `shop-agent-merge-failed`
ข้อความที่เพิ่มหรือแก้ต้องผ่านกติกาเนื้อหาชุดเดียวกับโปรโมชัน (ไม่อ้างผลต่อสุขภาพ · ไม่มีลิงก์ โดเมน อีเมล เบอร์โทร · อักษรอังกฤษเท่านั้น ·
ไม่มีอีโมจิหรืออักขระล่องหน · ไม่มีชื่อคนในทีม · คำเดียวไม่เกิน 24 ตัวอักษร · ห้าม `<` `>`) · คำว่า therapist ใช้ได้
ข้อความเดิมที่ไม่ได้แตะ ไม่ถูกตรวจซ้ำ
