# ประกาศบรรทัดเดียวบนหน้าแรก — `data/notice.json`

ข้อความสั้นบนสุดของหน้าแรก (ปิดชั่วคราว · เปลี่ยนเวลา) · `{"notice": null}` = ไม่แสดงอะไร (ค่าเริ่มต้น)
ไฟล์ผิดรูป ⇒ `next build` ล้ม ⇒ deploy ไม่เกิด

```json
{ "notice": { "code": "N-XMAS26", "text": "...", "starts": "2026-12-20", "ends": "2026-12-26", "link": "/contact" } }
```

| ช่อง | ความหมาย |
|---|---|
| `code` | รหัส ไม่เกิน 40 ตัวอักษร |
| `text` | ข้อความ ไม่เกิน 200 ตัวอักษร ห้ามมี `<` `>` ห้ามอีโมจิ |
| `starts` `ends` | วันที่ `YYYY-MM-DD` · แสดงตั้งแต่เที่ยงคืนต้นวัน `starts` ถึงเที่ยงคืนท้ายวัน `ends` เวลาลอนดอน (ตามนาฬิกาผู้เข้าชม) |
| `link` | ไม่บังคับ · path ในเว็บเท่านั้น เช่น `/contact` (ห้ามมีโดเมน) · แสดงเป็นลิงก์ "More" |

## การเปลี่ยนจากระบบร้าน (shop system)

สาขา `shop-agent/notice-<id>` · ไฟล์ `data/notice.json` · workflow `.github/workflows/auto-merge-shop-agent.yml` merge เองเมื่อด่านผ่าน แล้วสั่ง deploy

ระบบทำได้ / ห้าม
- **แทนทั้งช่อง** `notice`: ตั้งประกาศใหม่ หรือกลับเป็น `null`
- `text` ผ่านกติกาเนื้อหา ไม่เกิน 200 · `starts` `ends` เป็นวันจริง `starts` ไม่เกิน `ends` · `code` ตัวอักษร ตัวเลข `-` 2–40 ตัว
- `link` (ไม่บังคับ) ต้องเป็น path ในเว็บแบบ `/contact` หรือ `/services#cat-massage` เท่านั้น ห้ามโดเมน ห้าม `//` ห้าม `?`

ด่านทั้งหมดเหมือนโปรโมชัน (ดู `data/PROMOTIONS.md` หัวข้อ "การเปลี่ยนจากระบบร้าน"): PR แก้ไฟล์นี้ไฟล์เดียว ·
`npm run test:shop-agent` · `check-orphan-assets` · `next build` (ตัวตรวจของไฟล์นี้ใน `lib/`) · lint · `check:css` ·
`scripts/check-shop-agent-diff.mjs notice` · และ `main` ต้องยังไม่ขยับตอน merge · ไม่ผ่านข้อใด PR ค้างไว้ให้คน พร้อมคอมเมนต์ `shop-agent-merge-failed`
ข้อความที่เพิ่มหรือแก้ต้องผ่านกติกาเนื้อหาชุดเดียวกับโปรโมชัน (ไม่อ้างผลต่อสุขภาพ · ไม่มีลิงก์ โดเมน อีเมล เบอร์โทร · อักษรอังกฤษเท่านั้น ·
ไม่มีอีโมจิหรืออักขระล่องหน · ไม่มีชื่อคนในทีม · คำเดียวไม่เกิน 24 ตัวอักษร · ห้าม `<` `>`) · **ห้ามเขียนราคาหรือสัญลักษณ์เงิน** (`£` `€` `$`) ราคาอยู่ที่ `data/services.json` ที่เดียว · คำว่า therapist ใช้ได้
ข้อความเดิมที่ไม่ได้แตะ ไม่ถูกตรวจซ้ำ
