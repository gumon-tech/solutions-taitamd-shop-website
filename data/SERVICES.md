# เมนูบริการและราคา — `data/services.json`

เมนูบริการ (ชื่อ · คำอธิบาย · ระยะเวลา · ราคา) ที่หน้า /services และหน้า landing ทุกหน้า รวมถึงการ์ดหมวดบริการบนหน้าแรก
ไฟล์ผิดรูป ⇒ `next build` ล้ม ⇒ deploy ไม่เกิด · ตัวตรวจอยู่ที่ `lib/services.ts`

## ระดับไฟล์ (ไม่มีช่องอื่น)

| ช่อง | ความหมาย |
|---|---|
| `categories` | หมวดของเมนูราคา เรียงตามที่แสดง |
| `service_categories` | การ์ดหมวดบนหน้าแรกและ Services grid (`slug` `title` `subtitle` `highlights`) · หน้าแรกแสดงหกใบแรกที่ `slug` ตรงกับตารางภาพในโค้ด (`massage` `hair` `face` `nails` `waxing` `lashes`) |

## หมวด (`categories[]`)

| ช่อง | ความหมาย |
|---|---|
| `slug` | ตัวพิมพ์เล็ก ตัวเลข ยัติภังค์ · ไม่ซ้ำ · ใช้เป็นสมอ `#cat-<slug>` และหาหมวดในโค้ด ⇒ ห้ามเปลี่ยนชื่อ |
| `title` `blurb` | หัวข้อ (≤ 60) และคำอธิบายหมวด (≤ 240) |
| `image` | ไม่บังคับ · path ใต้ `/images/` ไฟล์ต้องอยู่ใน `public/` จริง · ตรวจขนาดก่อน commit (เว็บไม่ย่อรูป) |
| `services` | รายการบริการ |

## บริการ (`services[]`)

| ช่อง | ความหมาย |
|---|---|
| `name` | ชื่อ ≤ 100 · ไม่ซ้ำในหมวดเดียวกัน |
| `desc` `note` | ไม่บังคับ ≤ 200 · `desc` ใส่เฉพาะชื่อที่ไม่อธิบายตัวเอง · `note` แสดงใต้ชื่อ |
| `featured` | ไม่บังคับ · `true` เท่านั้น (ป้ายแนะนำ) |
| `variants` | ตัวเลือก 1–20 รายการ |

## ตัวเลือก (`variants[]`)

| ช่อง | ความหมาย |
|---|---|
| `option` | ไม่บังคับ ≤ 60 · แกนที่ต่างกัน เช่น ความยาวผม · ไม่มี = ใช้ระยะเวลาเป็นป้าย |
| `minutes` | จำนวนนาที เป็นจำนวนเต็ม 1–600 |
| `price` | `{ "gbp": 69, "wasGbp": 79 }` · `gbp` ราคาที่เก็บจริง · `wasGbp` ราคาก่อนลด (ขีดฆ่า) ไม่บังคับ ต้องไม่ต่ำกว่า `gbp` · ห้ามเขียนเป็น "from £X" (ราคาตายตัว) |
| `treatwell_sku` | `null` ตอนนี้ · ไว้ผูกกับรหัสบริการ Treatwell ภายหลัง (ตัวอักษร ตัวเลข `-` `_` ≤ 40) |

## ที่ยังอยู่ในโค้ด (`lib/catalog.ts`) เพราะมีคำวินิจฉัยทางกฎหมายผูกอยู่

`MEDICAL_NOTICE` · `CONSULTATION_ONLY` · `CATALOG_MEDICAL` (HIFU · SPMU · tattoo removal) · `PRODUCTS` · `SITE.signaturePrice`
